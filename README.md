# Mirror

Daily light-redirect puzzle. Place mirrors, bend the beam, hit the target
in as few mirrors as possible. Part of [NoodleGames](https://noodlegames.co).

See [GAME_DESIGN.md](./GAME_DESIGN.md) for the full spec.

```
npm install
npm run dev      # local dev server
npm run build    # production build
npm run deploy   # build + publish to gh-pages
```
